# Larpblox

Use your Larpblox look and name on the Roblox website. Install it once; your script manager handles updates.

## Install

1. Install **[Tampermonkey](https://www.tampermonkey.net/)** and follow its setup prompts. [Violentmonkey](https://violentmonkey.github.io/get-it/) also works.
2. If you have the old Larpblox extension, turn it off on your browser's **Extensions** page.
3. Click **[Install Larpblox](https://github.com/3xjn/larpblox-extension/releases/download/main-latest/larpblox.user.js)**, then click **Install**.
4. Refresh [Roblox](https://www.roblox.com/). Click your script manager's icon beside the address bar, then **Open Larpblox**.

[Step-by-step guide with a screenshot and troubleshooting](https://github.com/noahkcarmstrong-ops/larpblox/blob/main/docs/userscript-install.md)

Modern Greasemonkey APIs now have a compatibility adapter, including the Desktop connection. Automated browser checks cover this path; installation in Firefox with Greasemonkey has not yet been verified. Tampermonkey and Violentmonkey remain the managers tested with actual installations.

## Use it in games

You also need **[Larpblox Desktop](https://github.com/3xjn/larpblox-desktop/releases)** for game syncing. Install and open it, then follow the [in-game loading instructions](https://github.com/noahkcarmstrong-ops/larpblox#load-larpblox-in-roblox).

If Roblox asks for **Local network access**, click **Allow** so it can connect to Desktop.
